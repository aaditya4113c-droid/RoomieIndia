# RoomieIndia (सहपाठी) 🇮🇳
### Zero Brokerage Roommates & Flat Rentals for Indian Cities

A modern web application tailored for flat hunters, working professionals, and students in top Indian tech hubs (Bengaluru, Mumbai, Delhi NCR, Pune, Hyderabad).

---

## 🌟 Key Features

1. **Dual Modes**:
   - **Find a Room**: Browse vacant rooms in shared 2BHK/3BHK flats with existing roommates.
   - **Team Up to Rent**: Find flatmates to jointly rent an entire apartment and avoid brokers.
2. **India-Specific Matching**:
   - **Kitchen & Food Habits**: Strictly Vegetarian, Jain Food Only, Eggetarian, Non-Veg Friendly.
   - **Gender Preferences**: Male-Only, Female-Only, Unisex/Any, Couples-Friendly, LGBTQ+ Friendly.
   - **Transparent Recurring Costs**: Clear splits for Rent + Security Deposit + **Maid & Cook share** + Maintenance.
3. **60-Sec RoomieQuiz™**:
   - Compatibility score algorithm calculating % match based on habits, work schedule, and food preferences.
4. **Interactive In-App Chat & WhatsApp Connect**:
   - Built-in chat drawer with quick questions and automated response simulation.
   - 1-click WhatsApp connect.
5. **Post Room & Post Team-Up Wizards**:
   - Easy 3-step listing forms with instant updates and `localStorage` persistence.

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
npm start
```
